## 📌 نبذة عن المشروع (About The Project)
بوابة ويب تعليمية تعاونية، أُنشئت لخدمة طلبة قسم هندسة الحاسوب والاتصالات وتسهيل الوصول إلى كافة المحاضرات المسجلة، السلايدات، الكتب والمراجع المعتمدة، والتكليفات الدراسية دون انقطاع.

تم بناء البوابة وفق **نظام تصميم HP المعتمد (HP Design Language)** ومكتبة **Lucide Icons** الحديثة، مع مراعاة التصميم المتجاوب الفاخر على كافة الأجهزة وخاصة الهواتف الذكية (Mobile-First Responsive Design).

---

## ✨ المميزات الرئيسية (Key Features)

* **صفحة مستقلة لكل مقرر (Dedicated Course Pages):**
  * لا توجد نوافذ منبثقة مقيدة؛ كل مقرر دراسي يمتلك صفحة مستقلة بكامل تفاصيله وتقسيماته الأكاديمية.
* **أرشيف مودل مدمج (Moodle-Compliant Archive):**
  * تنظيم الفصول والسلايدات والملفات وفق الترتيب الرسمي المعتمد في منصة Moodle.
* **مشغل محاضرات تفاعلي (Integrated Lecture Player):**
  * دعم تشغيل محاضرات YouTube المسجلة ومشاهدة ملفات الفيديو المحلية (MP4) داخل واجهة الموقع بدون مغادرة الصفحة.
* **مجموعات التواصل المباشر (WhatsApp Communities):**
  * روابط مباشرة ومحدثة لجميع مجموعات المواد النظرية ومعامل التطبيقات العملية (طلاب وطالبات).
* **تصميم متجاوب مثالي للهواتف (Pixel-Perfect Mobile UI):**
  * أزرار إجرائية متناسقة، هيدر مدمج، شريط إعلانات نحيف، وتوافق تام مع شاشات الهواتف من أصغر قياس (360px) حتى شاشات سطح المكتب العريضة.
* **مكتبة أيقونات Lucide Icons مدمجة محلياً:**
  * تعمل 100% بدون الحاجة لإنترنت خارجي أو شبكات CDN.
* **دعم الوضعين الليلي والنهاري (Dark & Light Theme):**
  * مع حفظ التفضيل تلقائياً في المتصفح (`localStorage`).

## 🚀 التشغيل المحلي (Running Locally)

المشروع مبني بتقنيات الويب القياسية (Pure HTML5, CSS3, JavaScript) ويعمل على أي خادم ويب بسيط:

```bash
# باستخدام Python:
python -m http.server 8080

# أو باستخدام Node.js npx serve:
npx serve .
```
ثم افتح الرابط في المتصفح:
`http://localhost:8080/index.html`

## 🌐 النشر على GitHub Pages (Deployment)

المشروع جاهز فوراً للنشر المجاني عبر **GitHub Pages**:

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub.
2. ارفع ملفات المشروع:
   ```bash
   git remote add origin https://github.com/USERNAME/REPOSITORY_NAME.git
   git branch -M main
   git push -u origin main
   ```
3. ادخل على إعدادات المستودع **Settings** > **Pages**.
4. اختر الفرع `main` والمجلد `/ (root)` واضغط **Save**.
5. سيعمل الموقع مباشرة على الرابط: `https://USERNAME.github.io/REPOSITORY_NAME/`.
